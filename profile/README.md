## Who we are

**Raha Cloud** (رایانش ابر هوشمند رها) is an infrastructure consulting and DevOps-as-a-Service company.
We build reliable, automated, and scalable systems — and then we make them boring to operate.

Teams bring us in when deployments are manual, alerts are noisy, and nobody is quite sure what
production looks like. We leave behind pipelines that ship on their own, dashboards that answer
questions before they are asked, and infrastructure described entirely in code.

> Our mission is to deliver **freedom**, **reliability**, and **speed** in every aspect of
> infrastructure management.

## What we do

|  | Service | What that means in practice |
| :-: | --- | --- |
| ☁️ | **Cloud Infrastructure** | Provisioning, networking, and hardening across public cloud and bare metal — everything as code, nothing clicked in a console. |
| 🔁 | **DevOps &amp; CI/CD** | Build and release pipelines, GitOps workflows, artifact management, and repeatable, reversible deployments. |
| ⎈ | **Kubernetes** | Cluster design, migration, and day-2 operations — from single-node Talos to managed multi-tenant platforms. |
| 📈 | **Monitoring &amp; Observability** | Metrics, logs, traces, SLOs, and on-call rotations that page a human only when a human is actually needed. |

## Open source

A few things we build in the open:

| Project | What it does |
| --- | --- |
| [**kubernetes101**](https://github.com/rahacloud/kubernetes101) | Setting up Kubernetes from scratch, at small scale — the walkthrough we wish we had. |
| [**darkubectl**](https://github.com/rahacloud/darkubectl) | `kubectl`-like access to the Hamravesh Darkube platform. |
| [**oncall**](https://github.com/rahacloud/oncall) | On-call rotation as code — HTTP API, web UI, and ICS feed over a version-controlled Jalali schedule. |
| [**joghd**](https://github.com/rahacloud/joghd) | Blackbox monitoring for your public URLs, with notifications when something breaks. |
| [**arvanstatus-cli**](https://github.com/rahacloud/arvanstatus-cli) | ArvanCloud service status, straight in your terminal. |
| [**R2-DB2**](https://github.com/rahacloud/R2-DB2) | Your astromech droid for translating natural language into SQL. |
